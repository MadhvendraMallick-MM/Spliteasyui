## 📌 Project Overview

Urban commuters often need to process several pieces of information before choosing a route, including their destination, possible connections, and the overall journey.

The **Metro Route Planner UI** explores how a thoughtfully structured interface can make this information easier to navigate and understand.

The project connects interface design with product thinking by focusing on usability, information clarity, and the needs of everyday commuters.

### 🎯 Project Objectives

- Create a clear and intuitive interface for a metro route-planning experience.
- Organize journey-related information in a user-friendly format.
- Reduce unnecessary complexity in the user journey.
- Explore how design decisions can improve the overall customer experience.
- Translate a product concept into a frontend project.

## 💼 The MBA & Marketing Perspective

This project is not only about creating an interface. It is also an opportunity to apply business concepts to a practical digital product.

As a PGDM Marketing student, I approach product design by considering the relationship between **customer needs, user behaviour, perceived value, and the overall experience**.

### 1. Customer-Centric Thinking

A useful product begins with understanding the customer.

For commuters, the underlying need is not simply to view a screen. It is to make travel decisions with greater clarity and confidence.

This project encourages a user-first approach to identifying problems and organizing information around customer needs.

**Marketing connection:** Consumer behaviour, customer needs, and customer experience.

### 2. User Journey & Experience

Every interaction contributes to how users perceive a product.

A well-structured journey can make information easier to find, reduce friction, and help users move towards their goals.

Thinking through the commuter journey also highlights the importance of understanding user expectations at each interaction.

**Business connection:** Customer journey mapping, experience design, and usability.

### 3. Value Proposition

A digital product must communicate its value through the experience it delivers.

For a metro route-planning product, the intended value is a clearer and more convenient way to approach journey planning.

The design process provides an opportunity to explore how simplicity, accessibility, and information clarity can contribute to that value proposition.

**Marketing connection:** Value creation, positioning, and product differentiation.

### 4. Product Management Perspective

Product management requires balancing customer needs, business objectives, and technical feasibility.

This project provides a practical starting point for thinking about:

- **Problem identification:** Understanding the friction users may face while planning a journey.
- **Solution design:** Structuring an interface around a defined user need.
- **Prioritization:** Identifying which information and interactions matter most.
- **Usability:** Considering whether users can understand and navigate the interface.
- **Iteration:** Identifying opportunities to improve the product through user feedback.

The goal is to connect design decisions with the problem the product is intended to solve.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js and npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/MadhvendraMallick-MM/Spliteasyui.git
```

**2. Navigate to the project directory**

```bash
cd Spliteasyui
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### Production Build

To create a production build, run:

```bash
npm run build
```
